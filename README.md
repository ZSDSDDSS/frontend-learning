# 前端工程化学习仓库

本仓库致力于系统性梳理与实践前端工程化完整知识体系，沉淀日常学习笔记、可运行实践 Demo、开发过程中遇到的各类问题复盘以及行业主流最佳实践。内容覆盖模块化方案、主流构建工具链、代码质量规范约束、自动化测试、CI/CD 持续集成部署、项目构建与运行时性能优化等前端工程化全链路领域。

## 仓库简介

前端工程化是将前端开发的思维与工具解决前端项目开发、构建、检验、部署全流程问题，提升团队开发效率、代码质量与项目可维护性。

本仓库不仅直接功能上，更全面地旨在实践：从基础配置到完整项目脚手架，从零搭建多种开发工具链，构建可复用的工程能力体系，逐步探索前端代码工程化的能力与方向。

## 学习内容

- 模块化系统：ES Module、CommonJS、UMD 等
- 打包工具：Webpack、Vite、Rollup、Parcel、esbuild
- 代码规范：ESLint、Prettier、Stylelint、husky、lint-staged
- 自动化测试：Jest、Vitest、Playwright
- CI/CD：GitHub Actions
- 性能优化：构建优化、加载优化、运行时优化
